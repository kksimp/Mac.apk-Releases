# Mac.apk flags

The list of flags has moved to the wiki:

- **[Flags](https://github.com/kksimp/Mac.apk-Releases/wiki/Flags)**: what flags are, how to set them, and fixes for common problems.
- **[Flags Reference](https://github.com/kksimp/Mac.apk-Releases/wiki/Flags-Reference)**: every flag we support, with its default and what it does.
- **[Developer Menu](https://github.com/kksimp/Mac.apk-Releases/wiki/Developer-Menu)**: the hidden settings in the Mac.apk window, and how to unlock them.

Flags that aren't listed there are internal switches we use while developing Mac.apk. They aren't supported and can change or disappear in any release.
